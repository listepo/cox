# Fixtures

Recorded `TimelinePatch` streams for the Swift tests (DT§8): each JSON file holds the `batches` a `SessionHandle` pulled while a Scripted scenario played, and the final `snapshot`. Generated by `crates/cox-ffi/examples/record.rs` from the scenarios in `crates/cox-ffi/fixtures/`; do not edit by hand. Regenerate one with:

```bash
mise exec -- cargo run -p cox-ffi --example record -- \
  crates/cox-ffi/fixtures/read-and-reply.toml desktop/macos/Fixtures/read-and-reply.json "Read the notes"
```

Ids and timings change on every run.
