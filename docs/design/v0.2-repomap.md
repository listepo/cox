# Design: repo map scope gate (T19.6, amended T43.0)

## Problem

Large repos drown the model in `glob`/`grep` round trips. A repo map — a
compact structural overview (files, symbols, call edges) — answers "where is
X" in one lookup. The scoping questions: what it contains, what budget it
gets, and where it sits relative to cache breakpoints.

## The field

Aider's repo map is the reference: tree-sitter symbols, ranked by relevance,
capped at a token budget, refreshed on edit. cox already owns the pieces
(`outline` via tree-sitter in T3.2, `instruction_budget_tokens` precedent for
budgets, T8.1 compaction for staleness).

## cox

Scoped shape (creator decision 2026-09-28, plan.md §6 A74): a `repomap` block
assembled like instruction files (byte-stable inside the cache prefix, last
inside system[2], §1.9), contents = file tree + exported symbols per file
(tree-sitter `outline`), **ranked by recent git changes** — uncommitted paths
first (`git status --porcelain`), then paths from `git log` in order, then
remaining workspace files by path; outside a git repo, path order only.
Capped by `[context].repomap_budget_tokens` (default **0**, off, until T43.6
bench).

**Refresh policy:** built **once at session start**; rebuilt only on explicit
`/repomap refresh` (idle only; prefix restart when bytes change, recorded by
`Event::RepoMapBuilt`) or at **compaction** (rides the prefix restart
compaction already causes) — **never mid-turn, never automatic** on edit/write.

The map text is **archived** and **`Event::RepoMapBuilt`** records the archive
id and reason so **resume replays the same bytes** (invariant 6). Files denied
by `cox_permission::Engine` never appear in the map.

## Falsifiers

1. The map costs more context than it saves in tool calls — `just bench`
   (T8.5 harness) with map on/off decides; budget shrinks or the gate closes.
2. Staleness misleads the model (map says a symbol exists that an edit
   removed) — then the refresh hook is wrong, not the placement.
3. Stale map after many edits without refresh leads to wrong lookups often
   enough to waste turns — then the **refresh trigger** (when rebuild is
   allowed), not placement or ranking, changes.

## Review

Gate fixed per A74: git-recency ranking, session-start build, refresh only via
`/repomap refresh` or compaction, archived map + `Event::RepoMapBuilt` for
resume, default budget off until T43.6. Builder, wiring, and bench numbers
are the P43 implementation tasks.
